# CodexPro — workspace operations

## Purpose
CodexPro connects an AI assistant to explicitly allowed local development workspaces. File reading, editing, terminal commands and repository operations should remain scoped to the selected workspace.

## Workflow
1. Open the current workspace and confirm its root.
2. Read applicable project instructions.
3. Inspect files before modifying them.
4. Use expected hashes or atomic change sets when available to avoid overwriting concurrent edits.
5. Run tests and inspect the diff.
6. Report remote actions only after confirming their results.

## GitHub publishing
The local `gh` CLI uses the active authenticated GitHub identity. Check `gh api user --jq .login` before creating repositories. Use `git status` and `git diff --cached` to review the intended publication. Never commit `.env`, API keys, databases or virtual environments.
